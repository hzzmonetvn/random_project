# Days Together

A small anniversary landing page built with plain HTML, CSS, and JavaScript. The observatory, orbital lines, stars, glass fragments, and code-like texture are drawn in Canvas; no image or video assets are needed.

## Deploy on Vercel

Import this repository in Vercel and use the repository root. Choose **Other** as the framework preset. No build command or output directory is needed; Vercel can serve `index.html` directly.

## Personalize

- Change `START_DATE` near the top of `script.js` to update the live day counter.
- Edit the date and visible copy in `index.html` to change the page text.
- Adjust colors, typography, and layout in `styles.css`.

Google Fonts are optional; the page keeps system serif and monospace fallbacks.
